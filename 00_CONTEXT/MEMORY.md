# AutoAssist memory map

This file is the small always-loaded routing index. It must remain free of raw transcripts, credentials, authentication codes, payment data, unnecessary third-party details, and private chain-of-thought.

## First load

1. Read `../PROJECTS.md` and this file in full.
2. Read only the privacy zone and initiative status relevant to the current assignment.
3. Treat the user's newest explicit correction as authoritative.

## Canonical operating records

- `PRIVACY-ZONES.md`: classification and cross-zone rules.
- `OUTBOUND-ACTION-POLICY.md`: first-party write and attribution controls.
- `COMMUNICATION-PROFILES.md`: channel-isolated tone-learning index.
- `IDENTITIES.md`: user-confirmed account and destination labels. Created during first-time setup and never populated with credentials.
- `ISSUES/issues.json`: defect registry.

## Privacy-zone indexes

- `PRIVATE/INDEX.md`: sensitive personal context that is not about family or friends.
- `FAMILY_FRIENDS/INDEX.md`: relationship and personal communication context.
- `WORK/INDEX.md`: professional context.
- `SHARED/INDEX.md`: facts the user explicitly permits across zones.

The directories above are created by first-time setup with owner-only permissions. Do not infer their contents from their names and do not search another zone without assignment-specific need.

## Reconciliation rule

After substantive work, update the narrowest canonical record, the initiative status, and one compact session delta. Preserve one active truth per fact and retain corrections with provenance.
