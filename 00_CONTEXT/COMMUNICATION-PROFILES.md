# Communication profile index

AutoAssist keeps tone learning isolated by channel and audience. First-time setup creates only the profiles the user wants.

Recommended profile identifiers:

- `email-work-external`
- `email-work-internal`
- `chat-work-internal`
- `text-family-friends`
- `social-public`

Each profile should contain compact, user-approved observations such as greeting style, paragraph length, formality, punctuation, closings, directness, vocabulary to avoid, and a deterministic preflight. Do not retain raw correspondence by default. Never apply one profile to another channel or audience without explicit user direction.
