AutoBot vs OpenAI Dots

Dots work from an OpenAI cloud computer. AutoBot runs inside a local ChatGPT or Codex Project with memory and evidence the user can edit.

DimensionAutoBotOpenAI Dots
Primary runtimeLocal Project on the user’s MacOpenAI cloud computer, with optional handoff to a connected computer
MemoryReadable Project files with relationship and purpose zonesDot memory and task context managed by ChatGPT
CompletionOrdered evidence stages and a validator label separate from the producerCan create, inspect and steer delegated tasks
AvailabilityUses available local ChatGPT or Codex featuresEligible Pro tiers outside listed regions, Business Premium and administrator-enabled Enterprise, subject to rollout
Compatibility statusA Dot-to-local AutoBot canary has not yet been publishedLocal Codex handoff is documented by OpenAI

This comparison describes product boundaries from published documentation. It does not guarantee accuracy, security or reliability.
