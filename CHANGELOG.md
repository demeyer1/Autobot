# Changelog

## 0.3.0

First-time setup is now an active, resumable foreground walkthrough. It applies private local defaults, skips already verified work, preserves the earliest unresolved user or capability gate, and binds completion to the existing independent smoke, marker and status checks. Native Project, account, Computer Use and permission availability are reported separately; missing optional access never becomes a fabricated setup claim.

## 0.2.0

This release brings the current local operating model into a portable, empty workspace:

- Multiple promised outputs, explicit requirements and current evidence under one durable objective.
- Revision-aware corrections, independent acceptance, ownership and bounded recovery.
- Selective memory and context, local proof reuse, issue records and foreground handoffs.
- A transactional installer with explicit runtime readiness, upgrade preservation and recovery.
- Complete release inventories, stronger privacy checks and reproducible packaging.

The default folder remains `~/AutoAssist` so existing local Projects keep their path. New advanced runtime features require Node.js 22 or later; installation and inspection remain separate from native app availability. No personal accounts, history, contacts, schedules, notification recipients or standing spending authority are included.

Benchmark documentation and existing releases are preserved. No benchmark was rerun for this release. See the release's validation report for the exact tested package, platform, results and limitations.

## 0.1.0

Initial public workspace, shell objective stages, privacy zones, first-time setup and local liveness supervisor. Existing versioned assets remain available unchanged.
